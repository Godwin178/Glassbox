# Security Policy

## Reporting Vulnerabilities

Please report security vulnerabilities privately before making them public.

## Security Principles

- Glassbox never requests wallet private keys or seed phrases.
- Never store users' wallet secrets.
- Use public blockchain data for wallet inspection.
- Validate all user inputs.
- Keep RPC credentials in environment variables.
- Never expose server-side secrets in client code.

## Scope

Security issues affecting Glassbox source code, APIs, and data handling are in scope.
