# Glassbox

### Open-source Solana Transparency & Accountability Toolkit

Glassbox is an independent, open-source project designed to make Solana blockchain activity easier to inspect, understand, and verify.

## Our Mission

To make blockchain transparency accessible through clear, verifiable information and public accountability tools.

## Planned Features

- Solana wallet inspection
- Transaction verification
- Public funding transparency
- Expense tracking
- Project milestone tracking
- Community proposal tracking
- Public transparency reports

## Technology

- Next.js
- React
- TypeScript
- Solana Web3.js

## Security

Glassbox will never ask users for private keys or wallet seed phrases.

## Project Status

Development is beginning. Features will be marked complete only after implementation and testing.
